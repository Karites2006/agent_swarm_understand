# Swarm Chat & Agent Village Reporter

A Python-based NLP and LLM analytics tool designed to process, tokenize, and summarize complex multi-agent and human group chat transcripts.

This project ingests transcript data from the **Agent Village** AI experiment (and other agent conversation logs), pre-processes the text to optimize token consumption, and uses Groq/OpenAI-compatible LLM endpoints to extract executive summaries, key topics, and critical agreements.

---

## 📌 Features

* **Data Cleaning & Tokenization:** Uses `pandas` and `nltk` to remove punctuation, standard stop words, and irrelevant structural metadata from chat logs to minimize API token usage.
* **Automated LLM Reporting:** Integrates with `SwarmReporter` to query models (e.g., `openai/gpt-oss-120b` via Groq) for structured JSON outputs.
* **Structured Analytics:** Extracts executive summaries, key discussion topics, and agreed outcomes from raw multi-agent logs.
* **Multi-Format Support:** Handles structured `.json` files and `.jsonl` streaming chat logs.

## 🛠️ Installation & Prerequisites

### 1. Requirements

Ensure you have **Python 3.10+** installed. Install all required dependencies by running:

```bash
pip install pandas numpy jsonschema nltk requests openai tabulate
```

### 2. NLTK Download

The pipeline requires specific `nltk` resources for tokenization and stop word removal. You can pre-download them in Python:

```python
import nltk
nltk.download('punkt')
nltk.download('punkt_tab')
nltk.download('stopwords')
```

## 🚀 How to Use

### 1. Preprocessing Chat Transcripts

1. Place your chat dataset (e.g., `village-transcript.json` or `chat_messages.jsonl`) inside the `./json_data/` folder.
2. Open and run `notebook.ipynb`.
3. The notebook will:
   * Load raw event data into a `pandas` DataFrame.
   * Clean out unnecessary system event fields (`duration`, system wait flags).
   * Apply tokenization and English stop-word filtering using `clean_and_tokenize()`.
   * Export the structured output to `conversation.txt` in `[speakerName]: content` format.

### 2. Generating LLM Summaries

You can use the `SwarmReporter` class directly in a Python script or within the Jupyter Notebook:

```python
from SwarmReporter import SwarmReporter

# Load preprocessed conversation lines
with open('conversation.txt', 'r', encoding='utf-8') as f:
    conversation = f.read()

# Select a chunk of conversation lines to summarize
input_text = "\n".join(conversation.splitlines()[:50])

# Initialize the reporter and generate a structured report
reporter = SwarmReporter(api_key="YOUR_GROQ_API_KEY")
reports = reporter.generate_report(input_text)

# Display formatted report in console
reporter.print_formatted_reports(reports)
```

## 🔑 Configuration & API Keys

The default API configuration in `SwarmReporter.py` targets Groq's OpenAI-compatible base URL (`https://api.groq.com/openai/v1`). 

To use your own API key:
1. Pass `api_key="your_key_here"` when initializing `SwarmReporter()`.
2. You can optionally pass custom OpenAI/Groq endpoints via `base_url` or modify default model targets in `SwarmReporter.py`.
